# Shuaa DINOv2 ViT-S/14 fine-tuning trial

The prior frozen-encoder trial reached **74.2752% validation accuracy** and **54.8778% Macro-F1**. The current independently evaluated ConvNeXt V2 ensemble reaches **86.2712%** and **75.7370%**, respectively. This experiment tests whether limited adaptation of the DINOv2 image representation closes that gap. These are observations on Shuaa's validation split, not results from the [DINOv2 paper](https://arxiv.org/abs/2304.07193). The [official model card](https://github.com/facebookresearch/dinov2/blob/main/MODEL_CARD.md) describes ViT-S/14 and notes that fine-tuning is possible but should be considered cautiously.

Run `dinov2_small_last4` on the unchanged, duplicate-grouped benchmark split. Use the same `vit_small_patch14_dinov2.lvd142m` pretrained weights and 224×224 RGB/ImageNet-normalized inputs as the frozen comparison. Train only the classification head for two warmup epochs, then unfreeze the final four transformer blocks, output normalization, and head. Use AdamW with initial block learning rate 2e-5, head learning rate 2e-4, cosine decay, 25 configured epochs, early-stopping patience 7, and a 1.75-hour run allocation. The 2.2-hour notebook budget leaves time for setup, validation, ONNX export, and parity checking. Seed 42 is fixed for comparison. Horizontal and vertical flips are training-only; no test data is accessed.

Rank validation accuracy first and Macro-F1 second. Publish the measured record even if it does not beat the ConvNeXt model, but do not replace the leading result or call it a gain unless the independent CPU evaluation confirms one. Inspect minority-class confusion and paired errors before proposing an ensemble. A large validation gain from repeated experiments still needs a final locked test evaluation and, for deployment claims, an external farm holdout.
